Sudarsh own hardware/, core/, database/, firmware/ and tests/.

Himanshu owns ui/ and main.py.

Our stack is:
- Python — application logic
- Flet — desktop interface
- ESP32-C6 — hardware controller
- HLK-LD2410D — human presence detection beneath rubble
- MAX30100 — post-rescue heart rate and SpO₂
- PySerial — ESP32 communication
- SQLite — search-zone records


Sudarsh — Backend & Hardware

- ESP32 serial communication using PySerial.
- HLK-LD2410D sensor data acquisition.
- MAX30100 sensor data acquisition.
- Sensor data parsing and validation.
- Heart rate and SpO₂ processing.
- Human presence detection logic.
- Detection confidence and alert generation.
- SQLite database and data persistence.
- Backend APIs/interfaces for the UI.
  
Himanshu — UI & Application

- Flet desktop application.
- Dashboard layout and navigation.
- Live sensor readings display.
- Radar/presence visualization.
- Alert and notification interface.
- Search-zone management interface.
- Historical data visualization.
- Connection and sensor status indicators.
